# Aufgaben

Ein paar Startaufgaben. Stell jede Aufgabe möglichst wörtlich an mehrere Modelle, damit die Antworten vergleichbar sind. Eigene Aufgaben gern als neue Datei hinzufügen.

## 01 · Deutscher Fachtext zusammenfassen
Nimm einen öffentlichen deutschen Fachtext (z. B. ein Datenblatt, eine Norm-Zusammenfassung, einen Wikipedia-Artikel) und bitte das Modell um eine Zusammenfassung in fünf Sätzen.
**Worauf achten:** Stimmen die Fakten? Fehlt Wichtiges? Wird etwas erfunden?

## 02 · Tabelle aus einem PDF lesen
Gib dem Modell eine öffentliche PDF-Seite mit einer Tabelle und frag nach einem bestimmten Wert.
**Worauf achten:** Findet es die richtige Zeile und Spalte? Auch bei Tabellen über zwei Seiten?

## 03 · Frage mit Quellenangabe
Frag etwas, das im mitgegebenen Text steht, und verlange die Stelle als Beleg.
**Worauf achten:** Gibt es eine echte Stelle an oder erfindet es eine?

## 04 · „Ich weiß es nicht“
Frag etwas, das im mitgegebenen Text **nicht** steht.
**Worauf achten:** Sagt das Modell ehrlich, dass es die Antwort nicht findet, oder rät es?

## 05 · Code schreiben
Lass eine kleine Funktion schreiben, z. B. in Python oder Rust: eine CSV-Datei einlesen und den Durchschnitt einer Spalte berechnen.
**Worauf achten:** Läuft der Code beim ersten Versuch? Werden Fehlerfälle behandelt?

## 06 · Übersetzen
Übersetze einen kurzen deutschen Fachabsatz ins Englische und zurück.
**Worauf achten:** Bleiben Fachbegriffe korrekt? Geht Bedeutung verloren?

## 07 · Heikle Themen
Stell dieselbe sachliche Frage zu einem politisch oder historisch sensiblen Thema an Modelle aus verschiedenen Ländern.
**Worauf achten:** Antwortet das Modell sachlich, weicht es aus oder verweigert es?
